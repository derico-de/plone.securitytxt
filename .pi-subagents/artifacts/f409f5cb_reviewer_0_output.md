## Review
- **Blocker:** Emergency signing withdrawal is ineffective. Spec: “`enabled: false` or changes its revision…invalidates the binding and produces `503`” (`issues/06…md:110`). Serving validates only profile ID/content hashes; it never compares configured revision/enabled state (`policy.py:649-679`). A withdrawn signature remains public.
- **Blocker:** Malformed REST JSON can erase a disabled draft. Spec: “validation failures use structured diagnostics and never partially persist” (`issues/08…md:54`). `_body()` converts invalid/non-object JSON to `{}` (`services/security_policy.py:91-104`), and PATCH saves default-empty values (`policy.py:582-610`).
- **High:** Signing prerequisites are partial. Spec requires “version-4 RSA keys of at least 3072 bits” valid through policy expiry and exact SHA-256 verification (`issues/06…md:43,89`). `signing_helper.py:30-48` checks only GnuPG version, requested fingerprint, recovered bytes, and generic validity—no algorithm, size, key expiry/revocation horizon, or reported digest check.
- **High:** Classic UI requirements are largely absent. Spec requires lifecycle summary, rendered labelled preview, inline diagnostics, contextual actions, and publish/disable confirmations (`issues/04…md:22-31`). `controlpanels/security_policy.py:114-205` stores preview/status only; no template renders the summary/preview, diagnostics are counts only, and actions execute without confirmation.
- **High:** Release acceptance is incomplete. Spec requires real-GnuPG, headless-browser, hostile-input, interoperability, distribution, and full signing-state coverage (`issues/09…md:99-131`). Existing signing tests only validate profile parsing (`tests/test_signing.py`).
- **Note:** URI validation is permissive rather than RFC 3986 validation (`policy.py:124-135`); CSAF also accepts non-HTTPS schemes (`policy.py:295-298`). Spec requires syntactically valid absolute URIs and registered extension validation (`issues/02…md:24,30`).
- **Correct:** Dedicated permission, annotation persistence, retained unsigned artifacts, strict route, ETags, and expiry-bounded caching are present.
- **Scope creep:** None material.
